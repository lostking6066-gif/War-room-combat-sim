YouTube Battle Research — no API key needed

YouTube videos cannot be read automatically by a browser file without a YouTube Data API key, and scraping YouTube is blocked. So this version does the honest version that works on a phone: one-tap YouTube searches for each selected fighter, for powers, strength, speed and transformations, plus a channel library you can grow. Watching is research — it does not automatically add new powers to the combat engine.

WAR-ROOM AI — Five Connected Brains (rule-based, no paid API)

1. Combat Brain: tier scaling, counters, stamina, battlefield destruction — a street-level fighter cannot routinely hurt a cosmic foe by luck alone.
2. Character Brain: personality decisions — Batman studies first, Goku holds back to test a foe, Vegeta's pride seeks the strongest, protective fighters shield allies, humorous fighters are unpredictable.
3. Knowledge Brain: identity, continuity, powers, feats, limits, weaknesses, transformations, relationships — plus Wikipedia + Fandom research, shown per source.
4. Story Brain: turns recorded events into 5-chapter scenes, using tactics and reasons, not just attack names.
5. Continuity Brain: checks the battle before the story is shown — dead fighters must not act, powers must belong to that version, transformations must meet their trigger, winner must match the record.

Trade-off, stated plainly: this is a sophisticated rule system, not a language model. It can calculate, decide, and narrate from rules reliably, but it cannot write unlimited original prose like an LLM. That last step would need a local open model or a free/paid inference service, which v7 does not require.
